# ADR-0006：更新功能的菜单与通知呈现

- 状态：已接受（2025-08-24，grill-with-docs 访谈定稿；用户确认）

## 背景

提示形态用户已确认两条：系统通知（节流见 ADR-0005）+ 托盘菜单常驻入口；
明确**不要**图标角标（避免与运行状态色混淆）。剩余分叉是菜单布局。

## 决策

- **顶层动态升级项**：检测到新版本且未在升级中时，顶层菜单出现
  「🆕 升级到 x.y.z」（manual 类型则为「打开 DSH 发布页」）；无更新时顶层无痕迹。
  升级进行中该项置灰显示「升级中…」（防重入，ADR-0004）。
- **「检查更新」进帮助子菜单**：与「如何安装 DSH / 访问官方文档 / 打开日志目录」为邻，
  手动点击后无论有无更新必有通知反馈（ADR-0005）。
- **升级成功后的「重启以应用新版本」**：仅当托盘自管的 dsh 进程在跑时出现（复用
  restart 动作）；`external` 外部启动态下只通知“升级完成”，**不**提供一键重启——
  外部进程不归托盘管（与既有“只管自己启动的进程”原则一致）。
- 既有状态行/图标/其他菜单项一律不动。

## 后果

- 更新能力对菜单的侵入最小：无更新时与现状完全一致。
- `external` 态用户需自行重启外部实例（通知文案中说明）。
- 升级项文案带目标版本号，与 pin 策略（ADR-0003）所见即所得一致。
